# Employer & Employee Management App

A React Native (Expo) application built as an internship assignment for **3J Technologies**.

The application demonstrates an Employee Management System with separate Employer and Employee interfaces.

---

# Features

## Authentication

- Login Screen
- Role Based Login
- Employee Portal
- Employer Portal

---

## Employee Features

- Dashboard
- Attendance
- Leave Requests
- Tasks
- Announcements
- Profile

---

## Employer Features

- Dashboard
- Employee Directory
- Attendance Monitoring
- Leave Management
- Task Management
- Announcements

---

# Installation

Clone the repository

```
git clone https://github.com/yourusername/employer-employee-management.git
```

Move inside the project

```
cd employer-employee-management
```

Install dependencies

```
npm install
```

Start Expo

```
npx expo start
```
